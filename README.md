A fast, dependency-free frontend for make.fun bounties — live board, bounty pages, leaderboards and profiles, with a tiny first load.

## What it does

- `#/` — live bounty board.
- `#/bounty/<slug>` — bounty details.
- `#/bounty/<slug>/leaderboard` — bounty leaderboard.
- `#/profile/<handle>` — user profile.

No framework, with a tiny first load.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
